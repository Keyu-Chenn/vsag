# UHGH Recall@200/500/1000 dense-entry scale experiment

该批量实验复用原 `test_uhgh` 的定义：固定 `method=uhgh`、`alpha=0.7`，令
`dense_entry_ef_search = dense_entry_bk = entry_scale * ef_search`，比较
`entry_scale = 0.5 1.0 1.2 1.5 2.0` 的 Recall-QPS 曲线。

实验使用 `data/ground_truth_1000`，不会生成 GT。启动前会校验 alpha=0.7 的
fixed GT 宽度至少为 1000，并检查 HDF5 和预构建 UHG hybrid index。

默认搜索点：

| Recall | ef_search |
|---|---|
| 200 | `200 400 600 1000 2000` |
| 500 | `500 1000 1500 2500 5000` |
| 1000 | `1000 2000 3000 5000 10000` |

运行 NQ：

```bash
nohup bash scripts/UHG/run_test_uhgh_recall_200_500_1000.sh \
  > scripts/UHG/run_test_uhgh_recall_200_500_1000.log 2>&1 &
```

结果分别写入：

```text
scripts/UHG/results_200/test_uhgh
scripts/UHG/results_500/test_uhgh
scripts/UHG/results_1000/test_uhgh
```

生成三组对比图和 TSV：

```bash
bash scripts/UHG/plot_test_uhgh_recall_200_500_1000.sh
```
