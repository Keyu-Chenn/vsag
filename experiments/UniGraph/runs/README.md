# Run outputs

- `main/`: mixed alpha, fixed alpha, entry-point ablation, pruning ablation.
- `multi_weight/`: fixed-weight versus multi-weight graph ablation.
- `published/table_v/`: final values reported for Table V of `UniGraph.pdf`.

Every measurement keeps its command, raw log, metrics, and resumable completion
record. Experiment outputs, including the final figures and tables, are local
artifacts and should not be committed.
